# 快速开始

## 支持平台

星尘笔记提供 Windows、macOS、iOS、Android 四个客户端，另有网页版。

- Windows：Windows 10（1809）及以上
- macOS：macOS 12 Monterey 及以上
- iOS：iOS 15 及以上
- Android：Android 11 及以上

Windows 安装包大小为 86 MB，macOS 安装包为 92 MB。首次启动需要联网完成账号激活，之后可以离线使用。

## 注册与登录

支持手机号验证码、邮箱密码、微信扫码三种注册方式。企业用户可以通过 SAML 单点登录接入。

同一个账号最多可以同时登录 5 台设备，超出时最早登录的设备会被强制下线，并收到站内提醒。

## 界面结构

主界面分三栏：左侧是空间与笔记树，中间是编辑器，右侧是属性面板。

- 空间（Space）是最外层容器，一个空间可以有多个笔记
- 笔记支持无限层级嵌套，单篇笔记最大 200 万字符
- 属性面板可以给笔记打标签、设置提醒、查看修改历史

## 常用快捷键

| 操作 | Windows | macOS |
|---|---|---|
| 全局搜索 | Ctrl + K | ⌘ + K |
| 新建笔记 | Ctrl + Shift + N | ⌘ + Shift + N |
| 快速切换空间 | Ctrl + Shift + S | ⌘ + Shift + S |
| 打开命令面板 | Ctrl + / | ⌘ + / |
| 保存并同步 | Ctrl + S | ⌘ + S |

## 第一次使用建议

1. 先建一个个人空间，把常用的笔记类型（会议记录、读书笔记、项目文档）各建一篇模板；
2. 在设置里打开「自动同步」，默认同步间隔为 30 秒；
3. 如果团队要用，先在「团队空间」里建好目录结构，再批量邀请成员。

## 免费版限制

免费版可以创建 3 个空间，每个空间最多 500 篇笔记，单个附件上传上限为 50 MB。历史版本保留 7 天。
